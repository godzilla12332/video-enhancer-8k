# TikTok Video Enhancer 120 FPS

🎮 **Professional Video Enhancement Tool for TikTok, Free Fire & Mobile Gaming**

## Features
- ✅ Upscale video to perfect TikTok 9:16 aspect ratio (1080x1920)
- ✅ Convert any FPS to smooth 120 FPS with frame interpolation
- ✅ Professional denoising (removes grain and artifacts)
- ✅ Sharpening for clear, crisp details
- ✅ Contrast enhancement for depth
- ✅ Vibrant color boost for eye-catching content
- ✅ Perfect for Free Fire, PUBG, Call of Duty gameplay
- ✅ Works with all common video formats

## Requirements
- Python 3.8+
- OpenCV (installed automatically)

## Installation

### Windows
1. Download the folder
2. Double-click `run.bat`
3. Follow the prompts

### Mac/Linux
1. Download the folder
2. Open Terminal and navigate to folder
3. Run: `chmod +x run.sh && ./run.sh`
4. Follow the prompts

## How to Use

1. **Start the program**
   - Windows: Double-click `run.bat`
   - Mac/Linux: Run `python3 tiktok_enhancer.py`

2. **Select your video**
   - Enter the path to your video file
   - Supported formats: MP4, AVI, MOV, MKV, WebM, FLV, etc.

3. **Choose output name**
   - Default: `tiktok_enhanced_120fps.mp4`
   - Or enter a custom name

4. **Wait for processing**
   - Program analyzes video
   - Applies enhancements frame by frame
   - Interpolates to 120 FPS
   - Saves output

5. **Upload to TikTok**
   - Video is ready for upload!
   - Maximum quality and smoothness

## Troubleshooting

### "Python not found"
- Install Python from https://www.python.org/downloads/
- Make sure to check "Add Python to PATH"
- Restart your computer

### "Video file not found"
- Check the file path is correct
- Try using absolute path: `C:\Users\YourName\Videos\video.mp4`
- Make sure file extension is correct

### "Slow processing"
- Close other programs
- Use shorter videos to test
- Reduce other CPU usage

### "Output file is too large"
- This is normal! Enhanced 120 FPS videos are larger
- TikTok will compress it automatically
- Delete the original to save space
